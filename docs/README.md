# 🤖 Kael IA - Agente de IA Autônomo para Desenvolvimento de Jogos

**Kael** é um agente de IA autônomo projetado para desenvolvimento de jogos (Roblox, Godot, web, etc.) com foco em privacidade, execução local e capacidades cognitivas avançadas.

## 🎯 Características Principais

- **Execução 100% Local**: Roda na sua máquina via Ollama, sem enviar dados para a nuvem
- **Smart Sleep Híbrido**: Gerenciamento inteligente de VRAM baseado no contexto da conversa
- **Ferramentas de Sistema Seguras**: Execução de comandos de manutenção via allowlist rigorosa
- **Memória Persistente**: Banco de dados SQLite para contexto de longo prazo
- **Arquitetura Cognitiva Avançada**: Implementação de ReAct, Tree of Thoughts e Reflexion
- **Integração com Roblox**: Plugin para interação direta com o Roblox Studio
- **Descoberta de Rede**: Capacidade de interagir com dispositivos autorizados na rede local
